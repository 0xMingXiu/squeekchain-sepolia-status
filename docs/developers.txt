TL;DRLink to this section

SqueekCore V3, SqueekMining version 6, SqueekToken and SqueekNFT form one contract graph, deployed on the Sepolia testnet.

Every contract has a function-by-function page and a published ABI; addresses and identities are in one deployment record.

Verify the graph before trusting any read, and follow the integration invariants below.

OverviewLink to this section

Squeekchain's contracts record the hamster's settled work, issue SQK for completed Squeek blocks, and track the Squeeks that share it. Everything an integration needs is onchain: there is no SDK, and the public API reference is coming soon.

Where to start

First read: Quickstart verifies the deployment and reads SqueekCore in three files.

Working with a coding agent: Build with AI installs the squeekchain agent skill with npx skills add https://docs.squeekchain.com.

Wallets, marketplaces and agents acting for owners: Build owner actions prepares claims and merges for the owner's wallet to sign.

Indexers and analytics: Index events builds a projection that survives reorgs.

Exact ABI-level detail: the contract pages for SqueekCore, SqueekMining, SqueekToken, SqueekNFT and the DotGrid renderer.

Integration invariantsLink to this section

Verify before reading. Check chain ID, proxy implementation, runtime hash, layout digest, implementation version, governance owner, launch configuration and the links between the four contracts. See Verify the deployment.

One block per snapshot. Read everything at one Ethereum block and keep its hash.

Use bigint. viem returns bigint for uint64 and wider; never convert cumulative totals to number.

Count blocks from block units. Height is cumulativeBlockUnits / 1_000_000_000. Never divide physical work by difficulty.

Price with the previous difficulty. An event's difficulty prices the next active round, not its own.

Respect the certified frontier. Rounds after settledThroughRound are unknown, not zero. Every BatchSettled advances the frontier, including zero-work batches.

Read ownership live. Read ownerOf immediately before an owner action. Approved operators cannot claim or merge.

Prepare, don't sign. Claims and merges are signed by the NFT owner's wallet. Simulate every call and hand over unsigned calls; never hold or request a private key.

Count supply once. CheckpointMinted and the mint Transfer describe the same SQK.

Roll back on reorgs. Key events by (chainId, blockHash, transactionHash, logIndex) and replay derived state from the common ancestor.

Treat metadata as untrusted. Never inject a tokenURI SVG into application markup.

      Applies SqueekCore or SqueekMining upgrades authorized by its governing Timelock.

      Generates Squeek images and metadata from fixed onchain visual data.

      Calculates rewards from settled work, holds funded SQK, and pays eligible NFT owners.

      The Squeeks ERC-721 contract. Tracks NFT ownership and coordinates minting and merges with SqueekMining.

      The SQK ERC-20 contract. Enforces the lifetime supply cap; only SqueekMining can mint SQK.

      Queues governance operations and enforces a delay before they can be executed.

      Checks that visual data conforms to the required DotGrid format.

      When new power starts earning. Minting and merging schedule it for the next round, and a checkpoint applies it.

      A reward update that processes settled Squeek blocks, issues their SQK, and applies scheduled power changes.

      The Squeek permanently burned in a merge. Its unclaimed rewards move to the survivor, but its image is not combined or kept.

      Squeekchain's record of accepted wheel-magnet passages.

      Combining two eligible same-level Squeeks you own into one higher-level Squeek. One NFT is burned; the survivor keeps both Squeeks' unclaimed rewards.

      The completed Squeek blocks a Squeek waits through before it can merge again. It follows the Squeek through transfers.

      What a Squeek earns with. Its level sets its maximum power; each Squeek block's SQK is divided across all active power in proportion.

      A ten-minute period used to group measured work. The device saves a completed round's work total when measurement remained uninterrupted.

      The token each completed Squeek block issues, shared by active power. It has a lifetime supply cap.

      An NFT that owns a share of the Squeekchain network. It receives SQK from the hamster's work according to its active power, set by its level and the SQK staked to it.

      One billion block units earned from settled work at each round's difficulty. Completed blocks supply SQK under the mining reward rules.

      Squeekchain's ecosystem for hamster-powered onchain finance, built on the public work record.

      The Squeek you keep in a merge. It gains a level, keeps its ID and image, and receives both Squeeks' unclaimed rewards.

      A Squeek's recorded reward balance that hasn't been paid to a wallet. It stays with the Squeek when ownership changes.

      The hamster mining device. It records accepted wheel-magnet passages as work.
